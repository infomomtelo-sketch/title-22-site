# Video assets

Drop the demo assets here (this directory serves at `https://title-22.com/videos/`):

- `title22-demo-2min.mp4` — 9:16 vertical, ~2 min, 1080×1920, h264, muted
- `title22-demo-poster.jpg` — poster frame (~2s into the video), used as the
  video poster and the Open Graph / Twitter share image

Both files are referenced by `/demo/` (`demo/index.html`).
